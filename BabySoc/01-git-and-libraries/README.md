# Stage 1 – Git and Required Libraries

Commands used to set up the project folder and clone the BabySoC simulation repository:

```bash
mkdir baby_soc
cd baby_soc/
git clone https://github.com/Subhasis-Sahu/BabySoC_Simulation
cd BabySoC_Simulation
```
